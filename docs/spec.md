# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

その日の気分を色で1日1回記録し、1年分を1枚のモザイクで眺められるページ。（元のメモ：その日の気分を色で1日1回記録して、1年分を1枚のモザイクで眺められるページ）

言葉や点数ではなく、色だけで気分を残す。1年が埋まっていくのを1枚の絵として眺める。

## 前提

- 使う人：自分の気分を日々残したい個人。1人で、自分の端末のブラウザで使う
- 技術：Next.js（App Router）＋TypeScript、テストはVitest
- 日付は端末の現地時間で決める。「今日」は端末の時計の年・月・日
- 表示する年は今年だけ（前の年への切り替えは「あとで」）

## 画面

ページは1つ（`/`）。見た目は `docs/design.md` のとおり。

### モザイク

- 今年の1年分を「月 × 日」のマスで1枚に並べる。PC（幅 768px 以上）は 12行（月）× 31列（日）、スマホ（幅 768px 未満）は 31行（日）× 12列（月）
- その年に無い日（2/30、4/31、うるう年でない年の 2/29）はマスを描かない
- マスは3つに分かれる
  - 過去の日：記録があればその色、無ければ `--blank`
  - 今日：記録が無ければ色が移ろい、あればその色
  - 先の日：`--night`
- 横にも縦にもスクロールせず、1画面に収まる

### 記録する（今日）

- 今日のマスを押す（または Enter）、PC では今日の札、スマホでは `今日を塗る` ボタンを押すと、色の場が画面いっぱいに開く
- 色の場で、押したまま指（マウス）でなぞると選ぶ輪がついてくる。離しても閉じない。離した所の色が「今の色」
- `残す`（または Enter）で今の色を今日のマスに記録して閉じる。`やめる`（または Esc）は何も変えずに閉じる
- 記録は1日1回。ただし今日のうちは何度でも塗り直せる（記録後は札とボタンが `塗り直す` になる）
- 日付が変わると、その日は過去の日になり、もう変えられない
- 保存に失敗したら、色の場は閉じずに `残せませんでした` と `もう一度` を出す。`もう一度` で同じ色をもう一度残す

### 眺める（過去の日）

- 過去のマスを押す（または Enter）と、そのマスに縁が付き、上の帯に札が出る。札は日付（`3.14`）とその日の色の小さな四角。記録が無い日は日付と `なし`
- 札は 2.4 秒たつか、別のマスを押すと消え、今日の札に戻る
- 先の日のマスは押しても何も起きない
- 無い日の所を押しても何も起きない

### 記録の数

- 右上（スマホも上の帯の右）に `214 / 302日` の形で出す。前の数は今年の記録のうち今日までの日の数、後ろの数は今年の1月1日から今日までの日数（今日を含む）

### キーボード

- モザイクは1つのフォーカス先。矢印キーでマスを動かす。←→ は前の日・次の日（月をまたぐ）、↑↓ は前の月・次の月の同じ日（その月に無い日なら月末へ）。動けるのは今年の1月1日から今日まで
- フォーカスしたマスで Enter：今日なら色の場を開き、過去なら札を出す
- 色の場：←→ で色相を 2%、↑↓ で明るさを 4% 動かす（Shift で5倍）。Enter で残す、Esc でやめる
- 色の場を開いている間は、後ろの画面は操作できない。閉じたら開く前の所にフォーカスを戻す

### 記録の保存

- ブラウザの localStorage に保存する。キーは `mood-mosaic:v1`、値は `{ "YYYY-MM-DD": "#RRGGBB" }` の JSON
- 読むとき、壊れた値（JSON でない、オブジェクトでない）は空として扱う。形の合わない項目（日付や色の形が違う）は捨てる
- localStorage が使えない・書き込みに失敗したときは「保存に失敗した」として扱い、画面は壊さない
- サーバーには送らない。他の端末とは同期しない

## あとで（今は入れない）

- マスの出現の斜めの波、残したあとの波紋、色の場のばねの動き、札の点線が伸びる動き
- 前の年への切り替え（`2025` を押すとその年を表示）
