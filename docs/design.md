# デザイン仕様

画面の見た目のルール（色・文字・形・文言・動き）。画面に触る作業では、ここに書かれた物だけを使う。新しい色・文字・文言・寸法は、先にここへ書いてから使う。

## 体験の核

今日のマスを押すと、そのマスが画面いっぱいの色の場に広がり、指でなぞった所の色に染まる。離して「残す」と、色ごと1マスに縮んで1年の中へ戻り、周りのマスが波紋のように一度だけ明るく揺れる。

- 画面を開いた瞬間から、今日のマスだけが色をゆっくり移ろわせている（ここが唯一の「生きている」所）
- 1年が埋まるほど、背景に敷いた名前の文字が色の上に浮かび上がってくる（説明はしない）

## 構図

画面はパネルに分けない。1枚の WebGL の canvas が画面の端から端まで覆い、その上に、文字のある所だけすりガラスの帯を重ねる。

### モザイクの割り方

- マスは「月 × 日」。PC は **12行（1月〜12月）× 31列（1日〜31日）**、スマホは向きを変えて **31行（日）× 12列（月）**
- マスの間に隙間を作らない。角丸なし。マスとマスの境は、0.5px（デバイスの1ピクセル）の明るい継ぎ目 `--seam` だけ
- マスは縦横の比を固定しない。グリッドの枠（下の「枠」）にぴったり収まるよう、幅と高さを別々に割る（PC は縦長の長方形になる）
- その年に無い日（2/30、4/31 など）はマスを描かない。`--night` のまま継ぎ目も無し。右端（スマホは下端）が月ごとにでこぼこになるのを、そのまま見せる
- 枠の外（ガラスの帯の下）は、いちばん近いマスの色を引き伸ばして、明るさを 40% に落として描く。色は画面の端まで届き、マスそのものは端で切れない
  - 作り方：マスの色を 31×12 の小さなテクスチャ（1マス＝1ピクセル）に入れ、枠の中は最近傍、枠の外は線形補間＋端でクランプして読む

- 枠（マスを並べる範囲）：上 72px、左 56px、右 24px、下 24px を空けた残り全部。幅 1024px でマスは約 30×56px、2560×1440 で約 80×112px。どの幅でも 31 列が1画面に入り、横にスクロールしない
- 上のガラス帯（高さ 72px、画面幅いっぱい）
  - 今日の札：今日の列の左端に揃えて置く。`10.29`（見出し体・20px）と、その下に `今日を塗る`（12px）。札の下端から今日のマスの上端まで、1px の点線（`--ink-dim`、線2px・間3px）を引いて指す。札そのものが押せる
  - 日の番号：帯の下端（y = 54〜70px）に、各列の上に `1`〜`31`（12px・`--ink-dim`・列の中央揃え）。今日の列の番号は札と重なるので出さない
  - 右端：記録の数 `214`（大）＋ `/ 302日`（小）。その右に年 `2026`（20px）。前の年に記録があるときだけ、左に `2025`（`--ink-dim`）を出し、押すとその年に切り替わる
- 左のガラス帯（幅 56px、枠の上端から下端まで）：各行の中央に `1月`〜`12月`（12px・`--ink-dim`・左寄せ・左から 16px）。今の月だけ `--ink`
- ガラス帯は `backdrop-filter: blur(24px) saturate(1.2)` と `--glass`。モザイク側の端は `mask-image: linear-gradient(...)` で 16px かけて透明に消す（硬い境目を作らない）
- 名前の文字：`mood` と `mosaic` の2行。左下（左 24px、下 16px）。モザイクの上に `mix-blend-mode: overlay` で重ね、操作を受けない（`pointer-events: none`）。マスが暗いうちはほぼ見えず、色が増えると浮かぶ

```
│■■■■■■■■■■□□               │
│■■■■■■■■■■□□               │

```

- 枠：上 84px（帯 64px＋月の番号 20px）、左右 12px、下 76px＋`env(safe-area-inset-bottom)`。31行が最初の1画面に全部入る（高さ 667px で1行 約16px、幅 375px で1列 約29px）。縦にスクロールしない
- 上の帯：左に `10.29`（20px）と `今日`（12px）、右に `214`（大）＋ `/302日`（小）。帯の下に月の番号 `1`〜`12`（12px・列の中央揃え）
- 今日の行の左端の継ぎ目に、`--ink` の 1px 線を 8px だけ出して印にする（札は帯にあるので、点線は引かない）
- 名前の文字：`mood mosaic` を1行、幅いっぱい（`17vw`）。下の帯のすぐ上に `overlay` で重ねる
- 下の帯：左に年 `2026`、右に `今日を塗る` ボタン。片手の親指で届く所に主な操作を置く

## 色

画面の飾りの色はこの6つだけ。鮮やかな色は、使う人が選んだ気分の色だけにする（UIに差し色を持たない）。灰色は少しだけ紫に寄せる。

| 名前 | 値 | 用途 |
| --- | --- | --- |
| `--night` | `#0F0E13` | ページの背景。まだ来ていない日のマス。無い日の穴 |
| `--blank` | `#1D1C24` | 過ぎたのに記録が無い日のマス |
| `--seam` | `rgba(244, 242, 255, 0.08)` | マスとマスの継ぎ目（0.5px の光の線） |
| `--ink` | `#F2F0F7` | 文字、フォーカスの枠、色を選ぶ輪、今日の印 |
| `--ink-dim` | `#8E8A9C` | 単位、日と月の番号、点線、控えめな文字 |
| `--glass` | `rgba(15, 14, 19, 0.42)` | すりガラスの帯の地（`backdrop-filter` と一緒に使う） |

- 気分の色の上に文字を載せるとき（「残す」ボタンなど）は、その色の明るさ（OKLCH の L）が 0.62 以上なら文字を `--night`、未満なら `--ink` にする
- `#000` と `#FFF` は使わない

## 文字

Google Fonts の2書体だけ。`next/font/google` で読み込む（依存パッケージは増やさない）。

| 役 | 書体 | 太さ |
| --- | --- | --- |
| 見出し・数字・名前 | Bricolage Grotesque | 600、800 |
| 本文・日本語 | IBM Plex Sans JP | 400、500 |

大きさの段（この5つだけ）：

| 段 | 大きさ | 書体・太さ | 字間 | 使う所 |
| --- | --- | --- | --- | --- |
| 名前 | `clamp(120px, 19vw, 420px)`（スマホは `17vw`） | Bricolage 800 | -0.04em、行の高さ 0.8 | 背景の `mood mosaic` |
| 数 | PC 56px / スマホ 40px | Bricolage 800 | -0.03em | 記録の数 `214` |
| 見出し | 20px | Bricolage 600 | -0.01em | 日付 `10.29`、年 `2026` |
| 本文 | 14px | IBM Plex Sans JP 500 | 0.02em | ボタンの文字 |
| 小 | 12px | IBM Plex Sans JP 400（数字は Bricolage 600） | 0.04em | `今日を塗る`（札）、`/ 302日`、日と月の番号 |

- 数字はすべて `font-variant-numeric: tabular-nums`
- `214` の横の `/ 302日` は「小」の段で `--ink-dim`。下の線（ベースライン）を揃える。数を大きく、単位を小さく、の差で見せる
- 日付は `10.29` の形（月.日、0埋めしない）。曜日は出さない
- 日本語は 11.5px 未満にしない。`word-break: auto-phrase` を付け、文節の途中で折り返さない（文言はどれも1行に収まる長さにする）

## 動き

生きている映像は **今日のマスだけ**。ほかは、触ったときと状態が変わるときだけ動く。

| 何が | いつ | どう動く | 長さ・曲線 |
| --- | --- | --- | --- |
| 今日のマス（未記録） | ずっと | OKLCH で L 0.72・C 0.12 のまま、色相を 1秒に 12° ずつ回す。内側に 1.5px の `--ink` の縁 | 30秒で1周、等速 |
| 今日のマス（記録後） | ずっと | 残した色の明るさを ±0.03 だけ、ゆっくり呼吸させる。縁は消す | 6秒で1往復、sin |
| マスの出現 | ページを開いたとき1回 | 1月1日から斜めに、透明→不透明。遅れ＝（行＋列）× 12ms | 各 240ms、`cubic-bezier(.2,.8,.2,1)` |
| 色の場が開く | 今日のマスか札を押したとき | 今日のマスの長方形から、画面いっぱいへ広がる。最初の 160ms で、移ろう色から色の場へ溶けて変わる | ばね stiffness 380・damping 32（約 420ms） |
| 選ぶ輪 | 色の場に触れた瞬間 | 指の位置へ即座に移り、1 → 1.25 倍に膨らむ。離すと 1 倍へ戻る | 反応は 16ms 以内。大きさはばね stiffness 500・damping 28 |
| 色の場が閉じる（残す） | 「残す」を押したとき | 画面いっぱいから今日のマスへ縮む。最初の 120ms で、色の場から選んだ1色へ溶ける | ばね stiffness 420・damping 30 |
| 波紋 | 縮み終わった瞬間 | 今日のマスから外へ、各マスの明るさ（L）を +0.10 上げて戻す。遅れ＝今日からの距離（マス数）× 24ms。14マス先で止める | 上がるのに 80ms、戻るのに 360ms（`cubic-bezier(.2,.8,.2,1)`） |
| 色の場が閉じる（やめる） | 「やめる」か Esc | 縮んで今日のマスへ戻る。波紋は起こさない | 開くときと同じばね |
| 札の点線 | 過去のマスを押したとき | 札が出て、点線が札からマスへ伸びる | 180ms、`cubic-bezier(.2,.8,.2,1)`。2.4秒後に 160ms で消える |

- 押す操作には 100ms 以内に必ず目に見える反応を返す（マスは押した瞬間に縁が付く、ボタンは押した瞬間に 0.97 倍）
- 記録に成功したら、対応する端末では `navigator.vibrate(8)`
- `prefers-reduced-motion: reduce` のとき：今日のマスは色を回さず（色相 280° で止める）、マスの出現と波紋は無し、色の場の開閉はばねの代わりに 120ms の透明度の切り替えだけ
- 60fps を守る。canvas の解像度は `devicePixelRatio` を 2 までに抑える

### 作り方（canvas・WebGL）

- モザイク：画面全体に WebGL の canvas を1枚。マスの色は 31×12 のテクスチャ、継ぎ目・今日の縁・波紋・枠の外のにじみは、フラグメントシェーダーで描く。波紋は「今日の位置」と「始まった時刻」を uniform で渡す
- 色の場：モザイクの上に重ねる2枚目の WebGL の canvas。横（x 0→1）が色相 0°→360°、縦（y 0→1、上から下）で L = 0.92 − 0.62y、C = 0.16 ×（1 − y²）。OKLCH → sRGB に変換し、はみ出た値は 0〜1 にクランプする。上は明るく鮮やか、下は暗く色が抜ける（灰色や黒に近い気分も選べる）
- 残す色は、その点の sRGB を `#RRGGBB` で持つ
- WebGL が使えないときは、2D canvas で代わりに描く（マスは `fillRect`、色の場は 1/4 の解像度の `ImageData` を引き伸ばす）。動きは「動きを減らす」のときと同じにする

## 部品

ブラウザ標準のボタン・スライダー・色選び（`input type="color"`）は使わない。キーボード操作とフォーカスの見え方は必ず残す。フォーカスは `outline: 2px solid var(--ink); outline-offset: 2px`。マスのフォーカスは、マスの内側に 2px の `--ink` の縁をシェーダーで描く。

角丸は役ごとに決める：マス 0、ガラスの帯 0（端はぼかして消す）、ボタン 6px、選ぶ輪は円。影は使わない。

### モザイク

- 全体で1つのフォーカス先（`role="grid"`、`aria-label="2026年の気分"`）。矢印キーで日を動かす（PC は ←→ が日、↑↓ が月。スマホの向きでも同じキー）
- 過去のマスを押す／Enter：そのマスに 1.5px の `--ink` の縁が付き、上の帯（スマホも上の帯）に札が出る。札は `3.14` ＋ その日の色の 10px の正方形。記録が無い日は `3.14` ＋ `なし`。過去の日は塗り直せない
- 今日のマスを押す／Enter：色の場が開く
- 先の日のマスは押しても反応しない（縁も付けない）

### 今日の札（PC）・今日を塗るボタン（スマホ）

- PC の札：文字だけ。地は無し。押せる範囲は札全体（最低 44×44px）。押すと札の文字が 0.97 倍に縮む
- スマホのボタン：高さ 48px、左右の内側 20px、角丸 6px。未記録のときは地が `--ink`・文字が `--night`。記録後は地が今日の色（文字の色は「色」の決まりに従う）、文言は `塗り直す`
- 今日の色は、その日のうちは何度でも塗り直せる。日付が変わったら変えられない

### 色の場（開いたとき）

- 画面いっぱいの色の場。触れている点に選ぶ輪（直径 28px、2px の `--ink` の縁、中は今の色で塗る）
- 開いた直後の輪の位置：今日すでに残した色があればその点、無ければ前の日の色の点、どれも無ければ x 0.5・y 0.4
- 指（マウス）を押したままなぞると、輪がついてくる。離しても閉じない（離した所の色が「今の色」）
- キーボード：←→ で色相を 2%、↑↓ で明るさを 4% 動かす（Shift で5倍）。Enter で残す、Esc でやめる
- 左上の端（すりガラス・端をぼかす）：`10.29` と `今日の色`（12px）
- 下の端のすりガラスの帯（PC は右下に寄せる、スマホは画面幅いっぱい）：右に `残す` ボタン（地は今の色、高さ 48px、角丸 6px）、その左に `やめる`（文字だけ、`--ink-dim`、フォーカスで下線）
- 色の名前や気分の言葉（嬉しい・悲しい など）は付けない。色の意味は使う人が決める

### 空・読み込み・失敗

- 記録が1つも無いとき：説明の札は出さない。今日のマスが色を移ろわせ、今日の札が `今日を塗る` と指している状態がそのまま入口
- 読み込み中：枠の形どおりに `--blank` のマスを先に描き、色が来たら各マスを 200ms で色へ変える
- 残すのに失敗したとき：下の帯（PC は右下）に `残せませんでした` と `もう一度`（押せる文字）を出す。色の場は閉じずに開いたまま

## 避けること

- **GitHub の草のような見た目**：週×曜日の小さな正方形を、隙間と角丸を付けて並べた形。ここでは月×日の長方形を、隙間なく端まで敷く
- **カレンダーのパネル**：曜日の見出し、枠で囲んだ月ごとの箱、月を1つずつめくる操作
- **気分の決まった選択肢**：顔の絵文字、`嬉しい` `ふつう` などの言葉付きの色見本、5段階の点数
- **標準の部品**：`input type="color"`、色相と明るさのスライダーを並べた欄、画面の真ん中に出る「今日の気分は？」の箱
- **数のタイル**：「平均」「連続◯日」などを大きな数字の箱で並べること。数は `214 / 302日` の1つだけ
- **左上の小さいタイトル＋説明文**：名前は背景の巨大な文字だけ。サブタイトルは書かない
- **UIの差し色**：黒い地に蛍光の1色を足すこと、飾りのグラデーション（虹色は色の場の中だけ。あれは選ぶための物）
- **カードと影**：角丸の箱に薄い影を付けて並べること
- **等幅フォントの日付、字間を広げた大文字の小さいラベル、`→` 付きのボタン、中黒つなぎ**
- **硬い黒い線**：マスの間は光の継ぎ目（`--seam`）だけ。太い枠で囲まない
- **何でも中央揃え、全部に同じふわっと出る動き**：揃えは左揃えとグリッド。出現の動きはマスの斜めの波だけ
- **生きている映像を増やすこと**：今日のマス以外に、漂う粒子や光のゆらぎを足さない
